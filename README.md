# AI Hire Tool

An AI-powered Resume Rater built with **JavaScript, Node.js, Express, and Google's Gemini AI**.

## About the Project

AI Hire Tool is a web application designed to help users evaluate resumes using AI. It combines a frontend resume-upload interface with a Node.js backend that communicates with Google's Gemini API.

The goal is to make resume evaluation more accessible and demonstrate how AI can be integrated into a practical web application.

## Features

- Resume upload through the web interface.
- Resume scoring functionality.
- Backend API built with Node.js and Express.
- Google Gemini AI integration.
- Environment-variable configuration to protect API credentials.

## Technologies Used
